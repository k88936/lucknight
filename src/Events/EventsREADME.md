# Events Module Overview

## AnimationChangeEvent.h
Defines events related to animation state changes for entities.

## BodyEvents.h
Handles events involving physics bodies, such as collisions or state changes.

## BuffEvents.h
Manages events for applying, updating, or removing buffs on entities.

## GainEvents.h
Describes events for gaining resources, experience, or items.

## KeyEvents.h
Handles input key events from players or AI.

## LifeEvents.h
Manages events related to entity life state, such as spawning, death, or health changes.

## MoverEvents.h
Defines events for movement actions or state changes.

## ProjectileHitEvent.h
Handles events triggered when a projectile hits a target.

## WeaponShootEvent.h
Describes events for weapon firing actions.
