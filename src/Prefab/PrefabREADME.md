# Prefab Module Overview

## Prefab.h / Prefab.cpp
Defines and implements the `Prefab` base class for creating reusable game object templates.

## PrefabIndicator.h / PrefabIndicator.cpp
Handles prefabs for indicator objects, such as UI markers or in-game pointers.

## PrefabPlatform.h / PrefabPlatform.cpp
Defines prefabs for platform objects, used as static or moving surfaces in the game world.

## PrefabPlayer.h / PrefabPlayer.cpp
Implements the player character prefab, including initialization and configuration.

## PrefabProjectile.h / PrefabProjectile.cpp
Handles prefabs for projectile objects, such as bullets or missiles.

## PrefabTreasure.h / PrefabTreasure.cpp
Defines prefabs for treasure or collectible items.

## PrefabWeapon.h / PrefabWeapon.cpp
Implements weapon prefabs, used for equipping or spawning weapons in the game.

## PrefabREADME.md
Contains documentation for the `Prefab` module.
