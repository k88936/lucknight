# Systems Module Overview

## AnimationSystem.h / AnimationSystem.cpp
Manages animation updates and transitions for entities.

## AttachmentSystem.h / AttachmentSystem.cpp
Handles attachment and detachment of components or child entities.

## BuffSystem.h / BuffSystem.cpp
Applies, updates, and removes buffs on entities.

## HealthSystem.h / HealthSystem.cpp
Manages entity health, damage, and healing logic.

## KeyboardControlSystem.h / KeyboardControlSystem.cpp
Processes keyboard input and controls entity movement or actions.

## PhysicsSystem.h / PhysicsSystem.cpp
Handles physics simulation, including movement and collisions.

## ScriptSystem.h / ScriptSystem.cpp
Integrates and updates scriptable behaviors for entities.

## System.h / System.cpp
Defines the base system interface and common functionality for all systems.

## TreasureSystem.h / TreasureSystem.cpp
Manages treasure entities, including spawning and collection logic.

## WeaponSystem.h / WeaponSystem.cpp
Handles weapon logic, including firing, reloading, and switching.
