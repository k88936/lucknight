# Utils Module Overview

## Dumper.h
Provides utilities for dumping or logging data structures for debugging purposes.

## FileUtils.h
Defines file handling utilities, such as reading, writing, and file management operations.

## Registerable.h
Implements a base class or interface for objects that can be registered within systems or registries.

## Singletion.h / Singletion.cpp
Implements the singleton pattern, ensuring a class has only one instance and provides global access.

## Subscriber.h
Defines a subscriber interface or base class for event-driven or observer patterns.

## Wrapper.h
Provides generic wrapper utilities for encapsulating objects to box2d data.
